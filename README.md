# Vishakitha V — Static Portfolio

A responsive portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Keep the `assets` folder beside `index.html` so the résumé download works.

## Customize
- Update profile details and sections in `index.html`.
- Change colors in the `:root` variables at the top of `style.css`.
- Replace `assets/Vishakitha-V-Resume.pdf` with the latest résumé PDF, keeping the same filename.

## Included
- Responsive navigation and layouts
- Scroll reveal animations and floating hero artwork
- Draggable paper-note elements in the hero
- Recruiter-friendly résumé download links
- Email, phone, LinkedIn and GitHub contact links

All portfolio content is based on the supplied résumé. No framework or build step is required.
